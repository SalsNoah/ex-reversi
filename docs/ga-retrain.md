# GA 再学習（無操作ランダム着手・第100世代）

最終更新: 2026-09-15

無操作3秒の強制ランダム着手を入れたルールで、旧第10/20/30/40/50世代を第1世代の種として育成した。  
ラン ID: `ga1-train-003`

## 結果

| 項目 | 値 |
|------|-----|
| 種 | 旧第50/40/30/20世代＋`child-g10-2r4i2i-arch` |
| 世代 | 1〜100 |
| 選抜用試合数 | **192000**（1920試合×100世代） |
| アプリ導入 | 15, 20, 25, …, 100（18体） |
| デフォルト `ga_best` | 第90世代（`elite-g90-b0aih8`） |

対「当時のアプリ最強」12試合は、ピック時点の `ga_best` 相手。最新世代が最強とは限らない。

デフォルトは対代表・holdout・固定検証の順。第90世代は固定1.0 / holdout 1.0 / 対代表 1.0。第100世代も対代表12戦全勝だが holdout は約 0.83。
