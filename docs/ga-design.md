# GA-1 設計（遺伝的アルゴリズム育成）

最終更新: 2026-09-15  
仕様版: `GA_SPEC_VERSION = 1.0.0` / 遺伝子形式: `GENE_FORMAT_VERSION = 1.0.0`

PPO 経路とは独立。既存の TypeScript ルール（`src/game`）と画面なし対戦を直接使う。

## 目的

異なる評価係数を持つ CPU 集団を、対戦成績による選抜・交叉・突然変異・世代交代で進化させる。  
数万〜約10万試合の実行、チェックポイント保存、中断・再開を可能にする。

## 遺伝子 CPU（ニューラルネットではない）

- 個体: ID、世代、親ID、遺伝子配列（36）、形式版、評価、生成方法
- 36遺伝子 = 12特徴 × 序盤/中盤/終盤の3組
- 進行度 `(石総数 - 16) / 84` を 0〜1 に収め、0 / 0.5 / 1 の重みを線形補間
- 候補は合法手＋WAIT。仮着手後盤面（WAITは現盤）を評価し最大を選ぶ。同点はシード付き乱数
- クールタイム・反応速度は遺伝子に含めない（双方 700ms / 判断待ち 500ms 固定）

### 12特徴（自分視点）

| # | 内容 | 正規化 |
|---|------|--------|
| 1 | 石数差 | /100 |
| 2 | 角の石数差 | /4 |
| 3 | 自分の合法手数（盤面） | /100 |
| 4 | 相手の合法手数（盤面） | /100 |
| 5 | 空きに隣接する自分の石の数 | /100 |
| 6 | 空きに隣接する相手の石の数 | /100 |
| 7 | 空き角の斜め隣の自分石 | /4 |
| 8 | 空き角の斜め隣の相手石 | /4 |
| 9 | 角除く外周の石数差 | /32 |
| 10 | WAITなら1 | — |
| 11 | WAIT時のみ相手CD/700 | — |
| 12 | WAIT時のみ残り時間/180000 | — |

行動評価は `src/ga/geneCpu.ts` / `features.ts`（Node ファイルI/O非依存）。

## 本設定（変更しない実験値）

- 集団64 / 親候補16 / エリート8 / 子孫48 / 新規8 / 世代50
- 変異: 各遺伝子15%、N(0,0.2²)、[-3,3]、0件なら1強制
- 一様交叉 50%
- 親選択: トーナメントサイズ3
- 一次 1536 + 追加 384 = 1920試合/世代 → 50世代で 96000（検証は別カウント）
- 安全上限（検証込み）120000試合

## 続き育成（ga1-train-003）

無操作3秒のランダム強制着手を入れたルールで、現行の第10/20/30/40/50世代代表を第1世代の種にする。  
集団サイズ・変異・試合数/世代は本設定のまま。世代数だけ 100、安全上限は 250000。

- 開始世代 1、終了は世代100
- 15世代から5世代ごと（15, 20, …, 100）に固定検証・holdout・対現行最強で最強を選び、ブラウザCPUへ埋め込む
- パネルに現行最強（第50世代）をピン留め
- 固定検証にも第50世代を追加
- 結果: 選抜192000試合で第100世代まで完走。アプリは18体。デフォルトは第90世代（`docs/ga-retrain.md`）

## 長時間再学習（ga1-train-004）

見積もりレポート（`docs/ga-eval-estimate.md`）を反映した実験。

- 種: 現行採用モデルのみ（当時の `ga_best`＝第90世代 `elite-g90-b0aih8`）
- 開始世代 1、終了は世代 **400**（100世代ごとに許可を取ってから次ブロックへ）
- 一次評価は相手×色あたり1試合のまま
- 上位16の追加評価は相手×色あたり **3試合**（個体あたり+72、世代あたり合計約2688選抜試合）
- 20世代ごと（20, 40, …, 400）に固定検証・holdoutを厚くし、対現行最強は各色95試合（計190）で採用個体を選びアプリへ
- 安全上限 2_000_000 試合
- 世代が終わったときに Windows 通知「今○世代目が終わった」（`docs/ga-longrun.md`）
- 詳細: `docs/ga-longrun.md`

## 対戦パネル（世代開始前に12体確定）

- 前世代4（上位2＋その他2）
- アーカイブ4（古い世代も含む）
- 固定4: random / max_flip / 角位置係数 / 合法手係数

選抜得点: 勝1・分0.5・負0。得点率が主指標。石差は分析用のみ。

## 固定検証

選抜用得点率とは別。固定相手＋ホールドアウト個体＋固定シード＋黒白入替。  
世代横断の比較に使う。「最新世代＝最強」とは扱わない。

## 保存

`training/ga_runs/<run-id>/`（PPO 成果物とは別）

- `checkpoint-latest.json` / `checkpoint-genN.json`（原子的書き込み）
- `hall_of_fame/*.json`（既存は上書きしない）
- 乱数状態、完了試合ID、パネル、検証履歴

## 再現性

進化RNG・パネルRNG・試合シード・各CPU決定RNGを分離。固定マスターシードで世代交代まで再現。
