## 全体の順序

1. **ルール実装**（盤面・合法手・時間ステップ・同時着手・終了判定）
2. **画面と簡易CPU**（操作UI・表示・差し替え可能なCPU窓口）
3. **プレイテスト**（PC / スマートフォンでの通しプレイと不具合修正）
4. **強化学習**（学習済みCPUの学習・評価・差し替え）
5. **20段階調整**（レベル解放・難度調整・進行保存）

## 依存関係の方針

- 追加は必要性が明確なときだけ行う
- UIフレームワークや状態管理ライブラリは、標準の React で足りる間は入れない
- テストは Vitest を主とし、ルール層は DOM 環境に依存させない
- 画面なし CLI 実行に `tsx` を使用（ルールの二重実装はしない）
