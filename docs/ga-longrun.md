## 進行ルール

1. **第1〜100世代**を回し、20/40/60/80/100 をアプリへ導入したら **一旦停止**
2. チャットで許可を得てから **第101〜200世代**を開始
3. 同様に 201〜300、301〜400 も、前ブロック完了後に許可を取る
4. 許可なく次の100世代へ進まない

## コマンド

```bash
# 初回（第1世代から）
npm run ga:longrun

# 再開（例: 第100世代まで）
npm run ga:longrun:resume -- --generations 101

# マイルストーン導入
npx tsx src/ga/cli.ts pick-milestone --run-id ga1-train-004 --generation 20 --id ga_g20 --write-cpu --reset-milestones --versus-games 95 --panel-games 8

# 搭載個体の固定N試合総当たり（例: 第20/40/60世代を各100試合）
npx tsx src/ga/cli.ts tournament --games 100 --ids ga_g20,ga_g40,ga_g60 --seed 20260915 --out training/ga_runs/ga1-train-004/round-robin-g20-40-60-n100.json
```

読み取り:

- 直線的な強さではなく **循環相性**（第20 > 第40 > 第60 > 第20）。3体ともカードは1勝1敗。
- 第40世代が総合試合勝率では首位。第60を大きく崩し、第20には僅差で負けた。
- 第20 vs 第40 の6ポイント差は100試合ではノイズの範囲。第40 vs 第60、第60 vs 第20 は約15〜20ポイント差で、100試合でも片側が明らかに強い。
- 「新しい世代ほど強い」は、この3体では成り立たない。
- 1シードの結果であり、一般の強さは主張しない。
